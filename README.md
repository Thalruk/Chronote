# Chronote

A time-based kanban note-taking application. 

## Tech Stack

* **Frontend:** Angular, Tailwind CSS
* **Backend:** .NET 8 Web API, C#
* **Database:** PostgreSQL (Supabase), Entity Framework Core

## Overview

Project is currently under initial development. Setup phase includes monorepo configuration with strict PR reviews and standard kanban workflow.
